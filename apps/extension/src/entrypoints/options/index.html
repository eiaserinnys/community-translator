번역 서버

저장할 때 이 주소에 대한 접근 권한만 크롬에 요청합니다. 번역은 이 서버에서만 이루어지며, 다른 사이트나 외부 번역 서비스로 문장이 전달되지 않습니다.

번역할 커뮤니티

메시지 작성

자동 미리보기를 끄면 ‘번역하기’를 눌렀을 때만 초안을 번역합니다. 전송은 언제나 직접 하십시오.

번역 캐시

브라우저를 다시 열어도 같은 문장은 재사용합니다. 원문·주소·사용자 정보는 저장하지 않고 식별용 해시와 번역문만 저장합니다. 번역문에도 대화 내용이 포함될 수 있습니다.
